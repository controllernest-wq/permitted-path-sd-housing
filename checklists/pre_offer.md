# Pre-offer checklist

## File

- [ ] Credit pulled; score vs lender overlay (aim 660+ for most DPA)
- [ ] Written pre-approval naming FHA or conventional and 1–4 unit eligibility
- [ ] DPA product named; occupancy-acceleration clause read
- [ ] Homebuyer education certificate if CalHFA / SDHC is in play
- [ ] Reserves documented (3–6 months PITI)
- [ ] Gift letter template ready if using family funds

## Property

- [ ] Legal unit count matches county assessor + city permits
- [ ] If ADU/JADU: permit + final inspection + recorded JUA if required
- [ ] Not relying on unpermitted garage / laundry-room “unit”
- [ ] FHA minimum property standards look survivable (heat, roof, paint, safety)
- [ ] For 3–4 units: rough self-sufficiency rent test passed
- [ ] HOA docs: rental cap, FHA approval, special assessments
- [ ] Insurance quote obtained
- [ ] If DPA has vacant/owner-occupied seller rules, listing matches

## Numbers

- [ ] Row completed in models/cashflow_template.csv
- [ ] Year-1 (you in one unit) cash-to-you ≥ $0 after reserves
- [ ] Year-2 (you out) cash-to-you still works with 8% vacancy and 8% maintenance
- [ ] Exit-at-24-months tax case run if sale is the plan

## Offer terms

- [ ] Inspection, sewer, roof, permit-history contingencies
- [ ] FHA amendatory clause
- [ ] Seller credit asked (within program caps)
- [ ] Timeline compatible with DPA lender, not a 7-day cash fantasy
